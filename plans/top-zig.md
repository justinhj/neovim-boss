## Notes

- Research conducted September 2026; star counts are live snapshots and will drift.
- Verified top-20 coverage is incomplete — positions 9-20 on GitHub were not fully verified.
- Codeberg lacks a public global stars-sorted API, so Codeberg rankings may be incomplete.
- The GitHub ziglang/zig repo is a read-only archived mirror; canonical development is on Codeberg.

## Takeaways for neovim-boss

- **lightpanda/browser** (34k stars) is a direct spiritual sibling — headless Zig tool built for AI agents.
- **TigerBeetle** proves production-grade Zig infrastructure projects attract serious traction.
- **Ghostty** shows the community rewards focused, polished tools with a clear purpose.
- Pattern: fast, opinionated, well-named tools with AI or developer-tooling angles perform best.
